# Maintainers

This file lists the current maintainers of the cryptoptic project. Maintainers are responsible for reviewing contributions, managing releases, and guiding the project's direction.

See [GOVERNANCE.md](GOVERNANCE.md) for details on the role and how new maintainers are added.

## Responsibilities

- **Review & merge** pull requests in a timely manner.
- **Triage** new issues and label them appropriately.
- **Release management**: tag releases, publish changelogs.
- **Security**: respond to vulnerability reports per [SECURITY.md](SECURITY.md).
- **Community**: foster a welcoming and constructive environment.

## Contact

For questions about project maintenance, open a GitHub Discussion or reach out to the maintainers listed above.
